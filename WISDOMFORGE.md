# Pairing a child profile with WisdomForge

WisdomForge already speaks in three child bands. This kit makes a Hermes
profile that uses the same voice.

## What the parent does

1. Pick the band that matches the booklet: 5–10, 11–14, or 15–18.
2. Design the profile with `START-HERE.md`. Approve before anything is created.
3. Optionally add one USER.md fact: currently reading WisdomForge booklet
   **[figure title only]**. No school name, no address, no sibling details.
4. Use the agent beside the booklet: questions, Try This, Talk About It,
   Practice, Reflect — not a substitute for reading.

## What the agent must do

- Ask questions from the named figure. Do not recite the booklet.
- Keep hint-first learning. The booklet is the text; the agent is the guide.
- When a new WisdomForge figure ships, the parent may change the title fact.
  Do not widen tools just because the catalog grew.
- Point hard or tender topics back to a grown-up, same as the elementary
  **Ask a Grown-Up** section.

## What this is not

- Not a hosted WisdomForge chatbot.
- Not a way to put the public site’s full library into a child’s memory.
- Not a license to clone an adult SMF or parent Hermes profile so the child
  “can help with the catalog.”
