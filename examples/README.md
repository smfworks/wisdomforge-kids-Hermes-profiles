# Synthetic examples

Fictional profiles only. `SOUL.md.sample` is a filled seed, not a live
profile. Do not copy these into a real child's directory without a parent
design record.

| Folder | Band | Skills listed in `INSTALLED-SKILLS.md` |
|--------|------|----------------------------------------|
| `willow/` | 5–10 | ritual, homework, safety, capability, Try This, session-boundaries |
| `juniper/` | 11–14 | same plus optional journal |
| `cedar/` | 15–18 | plus integrity and ai-literacy |

Each folder: sample SOUL, USER, MEMORY, config snippet, design record,
installed-skill list, and short transcripts.

Generate a private copy with:

```text
python3 scripts/scaffold_child_profile.py --band elementary --profile willow --out ~/private-kids-kit
```

`--out` inside this repo is refused unless it is under `examples/`.
