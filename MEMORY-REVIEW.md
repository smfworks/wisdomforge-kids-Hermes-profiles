# Memory review (parent)

Use this before copying any fact from an adult profile or from family notes
into the child profile.

1. Ask the parent. Do not inspect another profile without permission.
2. Prefer coarse facts. Precise school, address, or schedule is never default.
3. Refuse: credentials, health diagnoses you inferred, crisis history, other
   children's data, anything the child asked to forget.
4. Write approved facts into USER.md using the seed format. Keep MEMORY.md for
   operational notes only.
5. Do not share one USER.md across siblings.

Record what was transferred, what was refused, and the date — in a **private**
file outside this repository.
