# Family notes (several children)

One child, one profile. This kit does not merge siblings.

## Rules

- Separate profile id, SOUL, USER, MEMORY, config, and design record.
- Do not share one USER.md across siblings.
- Skills may be the same *templates*. Installed copies live in each
  child profile. A change for one child is not automatic for another.
- `parental-session-review` is per profile. Ask for one child at a time.
- `family-isolation-check` is parent-invoked on one profile at a time.

## Naming

Use a display name the family already uses in speech, not a legal name
plus school. Profile ids stay short and boring (`willow`, `juniper`).

## Control plane

The adult Hermes profile is the control plane. It runs
`parent-setup-helper`, reviews, and pause/delete. It must not ingest
child MEMORY.md into the adult store.

## Aging one child

Band-change is per child (`MAINTENANCE.md`). A sibling staying in
elementary keeps the old tools.

## What this is not

Not a household account. Not a reason to give the oldest child an adult
colleague profile.
